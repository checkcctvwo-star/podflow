# ADR-004: 命名模板与文件夹组织约定

## 状态

Accepted

## 背景

用户要求下载的音频文件要有良好命名，并支持 mp3/wav/m4a 转换。同时 Android 与 Windows 都要能指定存储位置。

## 决策

1. **默认文件名模板**：`{title} - {show}`
2. **可用占位符**：`{show}` 节目名、`{title}` 集标题、`{ep}` 集数、`{date}` 发布日期（YYYYMMDD）
3. **文件夹组织**：根目录下按 `{show}` 分文件夹
4. **非法字符处理**：文件名与文件夹名中的非法字符替换为 `_`

## 理由

- 老板偏好"集标题 - 节目名"的显示顺序，默认模板满足此偏好。
- 占位符可自定义顺序，兼顾灵活性。
- 按节目分文件夹最直观，便于文件管理器浏览。
- 自动清理非法字符避免 Windows / Android 文件系统报错。

## 影响

- 命名模板存储在用户设置中，可修改。
- 下载完成后，根据模板生成目标路径，然后转码到该路径。
- 如果目标文件已存在，策略为覆盖或重命名（后续 ticket 细化）。
