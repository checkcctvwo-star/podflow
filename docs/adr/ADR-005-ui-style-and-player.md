# ADR-005: UI 风格与播放器设计方向

## 状态

Accepted

## 背景

用户提供了参考 UI 图片，希望界面简洁好看，同时软件本身要可以直接当播客 App 听。用户还强调"要有自己的特色"，避免开源后被指抄袭。

## 决策

1. **整体风格**：深色主题为主，支持浅色切换；底部三栏导航（收听 / 发现 / 我的）。
2. **布局参考**：参考图片的卡片式列表、时间线式 feed、圆角与渐变装饰。
3. **差异化**：
   - 使用 Material 3 设计系统，但自定义主题色与圆角。
   - 使用开源图标库（如 Phosphor、Material Symbols），不照搬参考 App 的图标。
   - 配色方案与渐变风格做差异化调整。
4. **播放器**：
   - 底部常驻 mini player，显示当前播放单集与播放控制。
   - 点击 mini player 进入全屏播放页。
   - 支持播放/暂停、进度拖动、倍速、睡眠定时、记忆播放位置、上一首/下一首。

## 理由

- 参考图提供的信息层级和导航结构已经经过验证，值得借鉴。
- 直接复刻图标/配色有版权与设计争议风险，必须做差异化。
- 播放器是"当播客 App 听"的核心，mini player + 全屏页是标准模式。

## 影响

- UI 开发需要更关注设计系统一致性。
- 播放器需要音频播放插件（如 `just_audio`）和后台音频处理。
- 需要做 golden test / 截图测试来保证 UI 质量。
